# FreeMusicService

Музыкальный сервис с открытым каталогом и поиском по названию песни и исполнителю. После входа пользователь может слушать песни в пределах своего допуска.

## Запуск

Для первого запуска создайте в корне файл `.env` по образцу `.env.example`. Задайте в нём пароли `COOLLOG56_PASSWORD` и `LOG42_PASSWORD` для учебных аккаунтов с допусками 2 и 1.

Из корня проекта выполните

```sh
docker compose up --build
```

По умолчанию сайт доступен по адресу http://localhost:8080.

## Безопасность

- **Защита от SQL-инъекций.** SQLAlchemy передаёт значения в запросы как параметры. При поиске символы `%` и `_` обрабатываются буквально.
- **JWT.** Токен хранится в cookie с `HttpOnly` и `SameSite=Lax`. При `APP_ENV=production` сервер добавляет `Secure`. При обращении к защищённым ресурсам сервер проверяет подпись и срок действия JWT.
- **Мандатный доступ.** Перед выдачей аудиофайла сервер сравнивает уровни доступа пользователя и песни. Без входа он возвращает 401, при недостаточном допуске возвращает 403.
- **Защита от Path Traversal.** Сервер проверяет полный путь к аудиофайлу и разрешает выдачу только из каталога музыки.
- **Argon2id.** Сервер хеширует каждый пароль с отдельной случайной солью.
- **Валидация данных.** Pydantic проверяет входные данные. При регистрации, входе и удалении аккаунта лишние поля отклоняются.
